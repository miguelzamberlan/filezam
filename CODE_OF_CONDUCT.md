# Código de conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1. Em resumo:

- Trate todas as pessoas com respeito. Discordâncias técnicas são bem-vindas; ataques pessoais, assédio e discriminação não são.
- Critique o código e as ideias, não as pessoas. Assuma boa intenção.
- Português e inglês são igualmente bem-vindos em issues, PRs e discussões.

Comportamento inadequado pode ser reportado ao mantenedor pelo e-mail do perfil [@miguelzamberlan](https://github.com/miguelzamberlan) no GitHub. Relatos são tratados com discrição; a resposta vai de um aviso até o banimento do projeto, conforme a gravidade.
